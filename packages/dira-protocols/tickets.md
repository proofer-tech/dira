# 티켓 - 이 프로젝트가 정하는 것

티켓 문법(만드는 절차 - frontmatter - 함정 - 확인)은 **코어 `CORE-TICKETS.md`에 있다** -
세션 프롬프트의 코어 블록 머리에 적힌 경로가 그 디렉터리다. 여기 남는 것은 아래 하나다.

## 쪼개는 기준

한 티켓 = **한 세션(5~25분) = 리뷰 가능한 하나의 변경**.

- 화면 하나, 레이어 하나, 검증 하나. "화면 3개 + 테스트"는 4개 티켓이다.
- `## Done when`이 6개를 넘으면 쪼갤 신호다.
- 쪼갠 것들 사이에 하드 선후가 있을 때만 `deps`로 엮는다. 병렬 가능한 것은 병렬로 둔다.
  **`deps` 한 줄이 사람의 40분이다**(실측 67건 - 깊이 1-2-3이 39m-73m-125m). 걸기 전에
  답한다 - *"이것 없이 착수하면 무엇을 모르나."* "몰라도 시작은 된다"면 안 엮는다.

## 에픽을 여는 주체와 시점

에픽을 여는 것은 pm이고, 여는 순간은 로드맵에 `### P###.` 블록을 작성하는 그 순간이다.
**여는 동작은 두 줄이다** - 그 블록과 함께 `epics/<P번호>/README.md`를 만들고 첫 줄에 사람이
읽는 제목을 적는다(안 적으면 화면에 `제목 없음 (P273)`으로 뜬다 - `epics.md` §라벨).
그 순간 쪼개는 티켓 전부가 같은 `epic:` 값(그 P번호 본체, 예 `P273`)을 받는다 - 형식과
저장 경로는 `epics.md`에 있다. 로드맵 항목 없이 티켓만 먼저 나면 `epic:`은 비워 둔다(정상, `(에픽
없음)`으로 모인다) - 나중에 로드맵 항목이 생기면 그때 채운다.

## 오토파일럿 큐의 티켓에는 멈춤 출구를 쓰지 않는다

주도성 안내가 오토파일럿이면 `## 방법`에 "못 구하면 멈춘다", "사람이 할 값을 적고 멈춘다" 같은 종료
조건을 쓰지 않는다. 세션이 그 문장을 정당한 출구로 읽고 시도 없이 멈춘다. 대신 시도할 길을 적는다.
외부 계정이 필요한 일은 `외부-계정.md`의 순서(CLI, API, 브라우저)를 가리킨다. 사람에게 넘길 값을
남기라는 요구는 세 칸을 다 실패한 경우에 한한다.
