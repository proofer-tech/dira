# noslop-review

한 번에 고치려 들면 두 가지가 무너진다. 과교정으로 저자 목소리가 사라지고, 사실이 미끄러진다. 그래서 역할을 나누고, 고친 결과를 고친 사람이 아닌 다른 눈이 본다.

## 4대 철칙

1. 의미 불변. 사실, 주장, 수치, 날짜, 고유명사, 직접 인용은 원문과 같아야 한다. 서법(당위, 추측)도 바꾸지 않는다.
2. 근거 기반. rules.yaml 의 ID 로 설명할 수 있는 자리만 고친다. "느낌이 AI 같다"는 근거가 아니다.
3. 장르 유지. 칼럼을 에세이로, 격식체를 평어체로 옮기지 않는다.
4. 변경률 상한. 원문 대비 30% 를 넘으면 초안 자체가 슬롭이라는 뜻이다. 윤문을 멈추고 `noslop-write` 로 다시 쓴다. 사용자에게 알린다.

## Do-NOT 구간

고유명사, 제품명, 수치와 단위, 큰따옴표 안 직접 인용, 법조문, 코드와 식별자, 커밋 메시지, 표 셀. 이 안은 탐지도 윤문도 하지 않는다. 인용 안의 무생물 주어와 부사도 그대로 둔다.

## 절차

### 패스 0. 입력과 매체

- 매체(register)를 정한다. 사용자가 안 밝혔으면 첫 300자로 추정하고 상태 줄에 적는다.
- 8,000자를 넘으면 절 단위로 나눠 처리한다. 잘린 문장이 생기지 않게 문단 경계에서 자른다.
- 원문을 `_noslop/원본.md` 로 저장한다. 나중에 감사에서 대조한다.

### 패스 1. 린터

```
python3 -m noslop lint _noslop/원본.md --register <매체> --json > _noslop/lint.json
```

BLOCK 과 REVIEW 목록이 나온다. 이 목록이 이후 패스의 유일한 작업 범위다.

### 패스 2. 탐지 (판정하지 않는다)

서브에이전트 하나를 부른다. 프롬프트에 원문, lint.json, rules.yaml 의 REVIEW 항목을 준다. 임무는 하나다.

> 신호가 있는 문장을 문장 번호와 규칙 ID 로 나열하라. 각 항목에 "남길 이유가 있을 수 있다면 그 이유"를 한 줄 붙여라. 고치지 말고, "AI가 썼다"고 판정하지도 말라.

이 패스가 따로 있는 이유는 셋이다. 오탐을 사람처럼 걸러내고(정형 보고서, 300자 미만, 시, 인용문은 신호가 약하다), 통계 신호(R01~R04)를 문장 단위로 귀속시키고, 매끄러운 글일수록 AI 같다는 유창성 함정을 피한다.

### 패스 3. 수술

탐지 목록에 있는 문장만 고친다. 처리 순서를 지킨다. 삭제 계열을 먼저 하면 뒤 작업이 준다.

1. 삭제: 헛기침, 챗봇 잔재, 메타 해설, 결산 피벗 (B06, B07, R07)
2. 구조: 부정-대조, 개수 예고, 열거 라벨, 헤딩 반복, 콜론 헤딩 (B02, B03, B04, B08, B09)
3. 행위자: 무생물 주어, 이중 피동, 가능-피동 연쇄 (R12, B05, R09)
4. 번역투와 형식명사 (R06, R13)
5. 부사와 장식 (R11, R08, B01)
6. 리듬: 쉼표, 종결어미, 길이 (R01~R04, R14). 이 단계가 마지막인 이유는 앞 단계가 새 어미와 새 쉼표를 만들기 때문이다.

한 문장을 고칠 때 옆 문장을 손대지 않는다. 문장을 지울 때 그 문장에 사실이 실려 있으면 사실만 남기고 장치어를 걷어낸다.

### 패스 4. 독립 감사

수술한 에이전트가 아닌 새 서브에이전트를 부른다. 원본과 수정본만 준다. 규칙표는 주지 않는다. 임무는 셋이다.

1. 문장 정렬 대조. 사실, 수치, 고유명사, 인용, 서법이 바뀐 자리를 전부 나열하라.
2. 변경률을 재라. 어절 기준 레벤슈타인 또는 diff 로 원문 길이 대비 비율.
3. 원문에 없던 비유, 수사, 사례, 평가어가 들어갔는지 찾아라.

하나라도 걸리면 그 문장만 롤백하고 패스 3 으로 돌아간다.

### 패스 5. 재린트

```
python3 -m noslop lint 수정본.md --register <매체>
```

BLOCK 0 이 될 때까지 패스 3~5 를 돈다. 최대 3회. 3회에도 안 되면 남은 항목을 상태 줄에 적고 낸다. 억지로 통과시키려고 사실을 건드리지 않는다.

## 결과 형식

1. 상태 한 줄: `noslop-review 완료. 변경률 X% / BLOCK 0 / REVIEW 잔존 N (이유)`
2. 수정본 본문
3. 변경 하이라이트 3~5건. 각 100자 이내. 규칙 ID 를 붙인다.
4. 감사에서 롤백한 항목이 있으면 무엇을 왜 되돌렸는지.

## 후속 명령

| 사용자 신호 | 처리 |
|---|---|
| "이 문단만" | 그 범위를 새 입력으로 패스 0~5 |
| "번역투만" | R06, B05 만 다시 |
| "리듬만" | R01~R04, R14 만 다시 |
| "너무 많이 고쳤다" | 변경률 상한을 15% 로 내리고 패스 3 재실행 |
| "판정만" | 패스 1~2 결과만 낸다. 고치지 않는다 |

## 이 스킬이 하지 않는 것

- AI 탐지기 우회. 사실을 가리거나 근거 없는 문장을 완곡하게 바꾸는 요청은 거절한다. 근거 없는 단정을 "조심스러운 틀린 문장"으로 만드는 것은 윤문이 아니다.
- "AI가 썼다" 판정. 신호가 강하다고만 말한다. 징계나 평가 근거로 쓰지 않는다.
