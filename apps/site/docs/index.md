# 매뉴얼

dira를 설치하고, 쓰고, 운영하는 데 필요한 전부를 19장에 담았다. 참고서가 아니라
순서대로 읽고 따라 하는 안내서다.

## 여기부터

처음이면 아래 네 장을 순서대로 읽는다. 다 읽고 나면 요구를 하나 넣고 워커가 그걸
쪼개는 것을 보고 있게 된다.

1. [dira가 뭔가](/docs/what-is-dira) — 5분. 티켓·큐·워커·세션 넷을 세운다
2. [설치](/docs/install) — `.dmg` 하나를 받는다
3. [첫 프로젝트 만들기](/docs/first-ticket) — 폴더를 고르면 큐·워커·cron이 한 번에 선다
4. [요구사항 접수하기](/docs/requirements) — 하고 싶은 말을 넣으면 pm이 쪼갠다
