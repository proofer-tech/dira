# 매뉴얼

dira를 설치하고, 쓰고, 운영하는 데 필요한 전부를 18장에 담았다. 참고서가 아니라
순서대로 읽고 따라 하는 안내서다.

## 여기부터

처음이면 아래 세 장을 순서대로 읽는다. 다 읽고 나면 30분 안에 첫 티켓이 돈다.

1. [dira가 뭔가](/docs/what-is-dira) — 5분. 티켓·큐·워커·세션 넷을 세운다
2. [설치](/docs/install) — 갈래를 고르고 엔진을 받는다
3. [첫 티켓 굴리기](/docs/first-ticket) — 10분. 워커 하나로 티켓 한 건을 손끝까지 돌려본다
