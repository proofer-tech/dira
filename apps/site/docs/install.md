# 설치

**받는 것은 `.dmg` 하나입니다.** 엔진이 앱 안에 들어 있어서 `git clone`할 것이 없습니다.

[최신 릴리스](https://github.com/proofer-tech/dira/releases/latest)에서 `.dmg`를 받아 열고
`dira.app`을 `응용 프로그램`으로 끌어다 놓으세요. 서명·공증된 빌드라 처음 열 때 Gatekeeper가
막지 않습니다. Gatekeeper는 맥이 낯선 앱을 열기 전에 세워 두는 관문입니다. 업데이트는 앱이
스스로 받습니다.

## 필요한 것

준비할 것은 셋입니다. 지금 하나도 없어도 순서대로 따라오시면 됩니다.

### 1. Apple Silicon 맥

앱은 여기서만 돕니다. 화면 왼쪽 위 사과 메뉴에서 `이 Mac에 관하여`를 열어 보세요. `칩`이
`Apple M`으로 시작하면 맞습니다. Intel 맥이라면 앱을 쓸 수 없습니다. 그 경우 아래
[앱 없이 엔진만 쓰기](#앱-없이-엔진만-쓰기)로 가세요.

### 2. 에이전트 CLI 한 종류

CLI는 창 없이 명령어로 쓰는 프로그램을 말합니다. 워커가 티켓을 물고 띄우는 세션이 이것이라
없으면 티켓이 `대기`에서 움직이지 않습니다. 기본값은
[`claude`](https://claude.com/claude-code)입니다.

깔려 있는지는 앱이 말해 줍니다. 방금 옮겨 놓은 `dira.app`을 열고 헤더 우측 끝의
톱니(`설정`)를 누르세요. `Claude 인증` 섹션의 맨 윗줄이 그 답입니다. 깔려 있으면
`claude CLI —` 뒤에 앱이 찾은 경로가 붙습니다. 없으면 `claude CLI를 찾지 못했습니다 — 워커가
세션을 띄우지 못합니다`라고 나옵니다.

못 찾았다고 나왔다면 위 `claude` 링크로 가세요. **설치 절차는 그쪽 안내가 정본입니다.** 이
매뉴얼은 남의 프로그램 설치 방법을 따라 적지 않습니다. 저쪽이 한 번 바뀌면 이쪽이 그날로
틀린 글이 되기 때문입니다. 설치를 마쳤으면 앱을 껐다가 다시 열고 같은 자리를 보세요. 앱이
프로그램을 찾아다닐 경로 목록은 켜질 때 한 번 정해집니다. 그 줄이 경로로 바뀌어 있으면
준비가 끝난 것입니다.

### 3. claude 장기 토큰

토큰은 로그인 대신 쓰는 긴 암호 한 줄입니다. 맥에는 로그인 정보를 넣어 두는 키체인이라는
금고가 있는데, cron으로 도는 워커는 여기에 붙지 못합니다. 그래서 토큰이 파일로 따로 있어야
합니다. 직접 만들 필요는 없습니다. 앱의 `설정` 다이얼로그가 대신 발급해 제자리에 놓아 주고,
그 절차는 [인증](/docs/auth)에서 다룹니다. 지금 없어도 설치는 끝납니다.

`python3`와 `bash`는 macOS에 이미 있습니다. 엔진이 쓰는 것은 그 둘의 표준 라이브러리뿐이라
따로 설치할 패키지가 없습니다.

## 앱 없이 엔진만 쓰기

화면이 필요 없거나 Linux에서 돌릴 경우입니다. 이 갈래는 레포를 직접 받습니다. 아래는
터미널에 입력하는 명령입니다. 터미널은 맥에 기본으로 들어 있는, 명령을 글자로 적어 넣는
앱입니다. `Command`+`Space`를 누르고 `터미널`이라고 치면 열립니다.

```bash
git clone https://github.com/proofer-tech/dira.git ~/Projects/dira
```

조직명은 하이픈이 있는 `proofer-tech`입니다. 하이픈을 빼면 존재하지 않는 계정이라 clone이 그
자리에서 죽습니다.

받았다고 뭔가 도는 건 아닙니다. `tick.sh`는 엔진 코드일 뿐이고 진입점은 워커입니다. 워커
파일을 손으로 만들고 cron에 거는 절차는 부록 [엔진만으로 돌리기](/docs/cron)에 있습니다.
앱을 같이 쓰셔도 상관없습니다. 앱은 자기 몫의 엔진을 번들 안에 따로 들고 있고, 둘 다 같은
큐 루트(`<프로젝트>/.dira`)만 보고 있으면 서로의 존재를 몰라도 한 큐를 같이 돌봅니다.

다음은 [첫 프로젝트 만들기](/docs/first-ticket)입니다.
