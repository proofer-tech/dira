# frontmatter 필드

사람이 쓰는 필드와 디스패처·엔진이 쓰는 필드는 갈린다([상태는 파일명](/docs/states)이
이미 그 경계를 세웠다). 사람이 쓰는 필드에 엔진 쪽 값을 미리 채워 넣으면 안 된다 —
예를 들어 `session_id:`를 채워두면 이미 할당된 것으로 보여 어떤 워커도 그 티켓을
집지 않는다.

## 사람이 쓰는 필드

| 필드 | 필수 | 뜻 |
|---|---|---|
| `ticket` | ✓ | 해시. 파일명과 같게 둔다(없으면 파일명에서 딴다) |
| `title` | ✓ | 사람이 읽는 제목 |
| `kind` | | `work`=지시 / `request`=부탁 / `feedback`=결과보고. 표시용이고 값을 강제하지 않는다 |
| `persona` | | 수행할 페르소나 이름. 없으면 페르소나 없는 평범한 에이전트가 처리한다. 알파벳·숫자·`-`·`_`만 통과한다 |
| `deps` | | `[<hash>...]` 하드 선후. 전부 완료여야 큐에 뜬다 |

## 디스패처·엔진이 쓰는 필드 — 사람이 직접 채우지 않는다

| 필드 | 쓰는 시점 | 뜻 |
|---|---|---|
| `session_id` | `assign` — 엔진을 띄우기 **전** | 있으면 할당된 것으로 보고 큐에서 제외한다. 판정이 보는 건 이 값 하나뿐이다 |
| `assigned_at` | `assign`과 동시 | 할당 시각(reap의 유예 판정에 쓰인다) |
| `owner` | `assign`(자동 디스패치) 또는 `handclaim`(손 클레임) | 자동이면 `<페르소나 또는 agent> / <워커>-<sid 앞8자리>`, 손 클레임이면 호출자가 준 식별자 |
| `pid` | `setpid` — 엔진을 백그라운드로 띄운 **뒤**, 또는 `handclaim`이 조상 `claude` pid를 기록 | 생존 확인용. 큐 제외 판정과는 무관하다 |
| `inbox` | `setinbox` — 최초 프롬프트 주입이 끝난 **뒤** | 참견 FIFO 경로. FIFO 파일은 세션이 끝나면 사라지지만 이 값 자체는 정상 완료·자동 스테일 회수로는 안 지워진다 — `unassign`이나 디스패치 실패로만 비워진다 |
| `claimed_at` | `handclaim` | 손으로 잡은 시각(유휴 판정 유예에 쓰인다) |
| `transcript` | `handclaim` | 그 순간 가장 최근 트랜스크립트 경로(유휴 판정용) |
| `attempts` | `reap`(회수할 때마다 증가) | 자동 회수 2회까지 세고, 답변 요청으로 전환되면 `0`으로 리셋된다 |
| `awaiting` | `reap`이 답변 요청으로 올릴 때(자동 회수 3회째, 또는 본문 마지막 절이 `## 블록`이면 횟수 무관 즉시) | 존재하지 않는 해시. `deps`처럼 걸려 큐를 잠근다 — 같은 이름의 답변 파일(`<awaiting>.done.md`)이 생기면 저절로 풀린다 |
