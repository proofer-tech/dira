설치

최신 릴리스에서 .dmg를 받아 열고 dira.app을 응용 프로그램으로 끌어다 놓으세요. 업데이트는 앱이 스스로 받습니다.

필요한 것

준비할 것은 둘입니다. 지금 하나도 없어도 순서대로 따라오시면 됩니다.

1. Apple Silicon 맥

앱은 여기서만 돕니다. 화면 왼쪽 위 사과 메뉴에서 이 Mac에 관하여를 열어 보세요. 칩이 Apple M으로 시작하면 맞습니다. Intel 맥이라면 앱을 쓸 수 없습니다. 그 경우 아래 앱 없이 엔진만 쓰기로 가세요.

2. 엔진 설정하기

dira가 동작하기 위한 CLI 기반 LLM 엔진이 필요합니다. 워커가 티켓을 물고 띄우는 세션이 이것이라 없으면 티켓이 대기에서 움직이지 않습니다. 기본값은 claude입니다.

방금 옮겨 놓은 dira.app을 열고 헤더 우측 끝의 톱니(설정)를 누르세요. Claude 인증 섹션의 맨 윗줄을 봐주세요. 깔려 있으면 claude CLI — 뒤에 앱이 찾은 경로가 붙습니다. 없으면 claude CLI를 찾지 못했습니다 — 워커가 세션을 띄우지 못합니다라고 나옵니다.

엔진을 설치하고 나면 앱을 껐다가 다시 열고 같은 자리를 보세요. 앱이 프로그램을 찾아다닐 경로 목록은 켜질 때 한 번 정해집니다. 그 줄이 경로로 바뀌어 있으면 준비가 끝난 것입니다.

워커가 티켓을 물고 이 엔진을 실행하는 동안 macOS가 권한이나 키체인 접근을 물어올 수 있습니다. 창에 뜨는 이름이 dira가 아니라 숫자(예: 2.1.222)로 보이는 건, 워커가 방금 설정한 CLI 엔진을 그대로 실행하기 때문입니다. 낯선 프로그램이 아니라 그 엔진 자신이 필요해서 띄우는 창이니 허용해 주시면 됩니다.

python3와 bash는 macOS에 이미 있습니다. 엔진이 쓰는 것은 그 둘의 표준 라이브러리뿐이라 따로 설치할 패키지가 없습니다.

앱 없이 엔진만 쓰기

화면이 필요 없거나 Linux에서 돌릴 경우입니다. 이 갈래는 레포를 직접 받습니다.

git clone https://github.com/proofer-tech/dira.git ~/Projects/dira
bash

워커 파일을 손으로 만들고 cron에 거는 절차는 부록 엔진만으로 돌리기에 있습니다. 앱을 같이 쓰셔도 상관없습니다. 앱은 자기 몫의 엔진을 번들 안에 따로 들고 있고, 둘 다 같은 큐 루트(<프로젝트>/.dira)만 보고 있으면 서로의 존재를 몰라도 한 프로젝트를 같이 돌봅니다.
