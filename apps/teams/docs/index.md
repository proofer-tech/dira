# 매뉴얼

## 목차

처음이시면 아래 순서대로 읽으세요. 네 장을 따라 하고 나면 dira는 이미 돌고 있을 겁니다.

1. [dira에 대하여](/docs/what-is-dira) - 5분. 티켓·큐·워커·세션을 이해합니다.
2. [설치](/docs/install) - `.dmg`를 받습니다.
3. [첫 프로젝트 만들기](/docs/first-ticket) - 폴더를 고르면 큐와 워커, 자동 실행 등록까지 한 번에 끝납니다.
4. [요구사항 접수하기](/docs/requirements) - 하고 싶은 말을 넣으면 pm이 티켓으로 쪼개 줍니다.
